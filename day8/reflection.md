# Day 8 Reflection

The most difficult concepts in this course were working with APIs and designing databases for my capstone. At first, it was challenging to understand how the front end, API requests, and stored data fit together. I worked through this by building the features step by step, testing requests and database queries, and checking how the pieces behaved together instead of trying to solve the whole system at once.

Based on the feedback I received, I would improve the capstone by making the empty-notes state clearer and easier to access. I would also plan the front-end structure and navigation more carefully, strengthen the database design, and make sure the backend can handle requests without becoming overwhelmed. The honesty and compassion of the audience made the feedback encouraging and useful; it helped me see specific ways to improve rather than treating the project as finished just because its main features worked.

Next, I want to learn more about building backend APIs and connecting them reliably to relational databases. I would like to practise database transactions and constraints, then use load testing to find bottlenecks before they become problems for users. That would help me design systems that are not only functional but also clear, dependable, and ready to grow.
